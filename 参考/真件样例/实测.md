## 二、五条结论，三条推翻了我原来的写法

### 1｜篇幅上限我写错了一个数量级

SKILL.md 原来写"法定公文没有标准篇幅，508—6,927 字都正常"。这个区间来自旧样例库里七篇的最大值，不是真实上限。

实测最大的是**福建省政府工作报告，21,513 字**。所以正确的说法是：**从六百字到两万多字都有，取决于文种**。批复、复函在千字以内；工作部署类通知两三千；工作报告可以两万以上。

已改。

### 2｜法定公文不能用"句长"自检，这个指标会失真

「决定」那一行的句长 147.0，看着像异常，其实是结构造成的：科技奖励决定里那句授予名单是这么写的——

> 授予陈立泉院士、贲德院士国家最高科学技术奖；……授予「单原子催化」等 3 项科技成果国家自然科学奖一等奖，授予……

整段名单 **424 字，用逗号串起来，全篇只有 1 个分号**。算法按句号、问号、感叹号、分号切句，于是这一大坨算作一句——而这一句占了全文五分之二，把平均值直接顶到 147。

这不是算法错，是**名单式、条款式文本本身没有"句子"这个概念**。判决书式的"一、同意……二、……"也一样。所以：法定公文只查三样——**承启句对不对、层级分条合不合体例、篇名要素齐不齐**。句长、顿号、句数这些指标不用看。

**补充一个反例，免得把话说过头**：两篇批复的句长是 69.6 和 84.7，比事务性材料的 53—64 高一档，但**不算失真**——批复一条一句，句长本来就等于条长。所以失真的判据不是"数值大"，是**通篇没有句末标点、靠分号串句**。跑一下看句数：句数只有个位数而字数上千，就是失真；句数正常，句长照样可看。

### 3｜强制词比我说的更稀缺——稀缺得多

我在 SKILL.md 里写"强制词是稀缺资源，多数文种一篇只该有 0—2 个"。实测更极端：

```
10 篇强制词中位数：0 个
最高的那份（中小企业回款难通知，2450 字）：5 个
4498 字的养老服务指引：只有 1 个"应当"，"必须""不得""严禁"全部为 0
```

四千多字的规范性文件，全篇只有 1 个强制词。这是真件的样子。

对照我原来的提示"写规范性文件时每提一条约束顺手写个'不得'，很容易一路堆到七八个"——**那句写的是 AI 初稿的毛病，不是真件的习惯**。真件的做法是用陈述句把要求说清楚，把"不得"省给真正需要禁止的那一两条。

已改：把两个数字摆进去。

### 4｜三级标题只属于"指引/办法/细则"，正式发文主体不用

十篇里只有民政部那份养老服务**指引**用了三级标题，29 个。其余九篇全是 0。

原因很明确：那份文件是"通知 + 附件（指引）"的结构，附件是条款式规范文本，按"1. 2. 3."排；通知本体的正文仍然只有两级。

所以"法定公文按条例分条"这句话太粗。准确说法：

```
通知/批复/意见/通报的正文   → 两级（一、二、三 ＋（一）（二）（三））
指引/办法/细则/方案 等附件   → 三级（1. 2. 3.）
```

### 5｜破折号 10 篇里 0 个

这条直接印证了原来写的"一篇不超过 1 个，0 个最好"。不是最好，是**真件里根本不出现**。十篇、四万多字，破折号 0 个。

## 三、一级标题不是两种形态，是四种

我原来只写了"标题式"和"条款式"两种，逐篇核对后发现有四种，而且**通知内部就占了两种**：

| 形态 | 长相 | 见于 |
|---|---|---|
| **独行式** | `一、重点任务` 单独一行，正文从下一行起 | 意见×2、通知（2号、24号）、通报 |
| **合体式** | `一、做好宣传解读。要将《指引》迅速传达……` 标题＋句号＋正文挤在同一段 | 通知（民函41号）正文五条 |
| **条款式** | `一、原则同意《方案》，请认真组织实施。` 整条就是规定，下面没有正文 | 批复×2 |
| **不分条** | 通篇没有"一、二、三"，段落直推 | 决定（科技奖励） |

**合体式是最容易被漏掉的一种，偏偏是基层最常用的**——它把标题当"段首提要"用，省掉一行。写工作部署类通知时，合体式比独行式更省篇幅、更像部门口吻。

**不分条也有正当场合**：表彰决定、任免通知这类，内容就是"依据＋名单＋号召"，硬套"一、二、三"反而假。

判据只有一条：**这一层是不是要当目录用**。要当目录（六个块以上、读者要跳读）就独行；三五个块、每块一句话能说完，合体更合适；每块本身是规定，就条款式。

## 四、两条顺带发现

**顿号密度跨文种很稳定。** 这十篇在 13.6‰—38.8‰，中位 23.5‰，跟事务性材料的 14—31‰ 是同一个量级。说明顿号密度是**汉语公文的通用指纹**，不分文种都成立，可以放心拿来当验收项（法定公文除外，因为它不需要验收）。

**百分比要按文种看。** 政府工作报告 48 处，其余九篇几乎为 0。这跟"经验总结零百分比"是同一个道理的两面：**报告类要向代表/上级交账，必须有数；意见、通知、批复讲的是要求，不是成绩，不摆数**。
