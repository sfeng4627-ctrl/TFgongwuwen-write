# 十篇真件的写法提要

`提炼.md` 是脚本自动生成的，重跑会覆盖。这份是人工总结——看那十篇真件之后，**能直接拿去用的东西**。

数据来源见 `实测.md`，原文见同目录 `.txt`。

## 一、「一、二、三」有四种，用错就是体例错

同样是"一、二、三"，在真件里干的是几件完全不同的事。逐篇核对下来是**四种**，不是两种：

| 形态 | 长相 | 见于 | 标题写法 |
|---|---|---|---|
| **独行式** | `一、重点任务` 单独一行，正文从下一行起 | 意见×2、通知（2号、24号）、通报 | 可以只写两三个字（"支撑保障""组织实施"），因为下面还会展开 |
| **合体式** | `一、做好宣传解读。要将《指引》迅速传达……` 标题＋句号＋正文挤在同一段 | 通知（民函41号）正文五条 | 标题当"段首提要"用，一句话勾出这段干什么 |
| **条款式** | `一、原则同意《方案》，请认真组织实施。` 整条就是规定，下面没有正文 | 批复×2 | 必须一句话把事说完，因为下面没有正文了 |
| **不分条** | 通篇没有"一、二、三"，段落直推 | 决定（科技奖励） | 依据＋名单＋号召，五段到底 |

**合体式是最容易被漏掉的一种，偏偏是基层最常用。** 它省掉一行，读起来更像部门口吻而不是文件口吻。写工作部署类通知时优先考虑它。判断依据是这一层要不要当目录：要跳读就独行，三五个块且每块一句话能说完就合体。

**不分条也有正当场合。** 表彰决定、任免通知这类，内容就是"依据＋名单＋号召"，硬套"一、二、三"反而假。

**最容易犯的错**：写批复时套了意见的独行式，出现"一、总体要求"下面再展开一段——批复不该有"总体要求"这一层。

## 二、二级标题有三种句式，按文种选

十篇真件里的二级标题（"（一）（二）"这一层）呈现出清晰的三种句式：

**句式甲：动宾短语＋句号**，下面接整段。意见和规范性通知的主流写法。

```
加强随迁子女教育保障。
扩大公租房保障范围。
健全就业地参加职工社会保险制度。
加强改进大型企业支付行为监管。
分行业明确合理账期。
```

意见（国发11号）那篇 13 条、通知（国办发24号）那篇 10 条，**23 条全部以动词或"状语＋动词"开头**（加强×4、完善×2、优化×2、规范×2、扩大、健全、强化、促进、推动、开展、发挥、畅通、加大、分行业明确、严格反不正当竞争执法、从严监管），**没有一条写主语**——主语就是主送机关，不用重复。

**句式乙：名词短语＋句号**，用于罗列领域或对象。服务消费那篇全篇如此。

```
交通服务。
家政服务。
网络视听服务。
旅居服务。
入境消费。
```

**句式丙：双动宾对仗，中间逗号，不用句号**。通报和报告的写法。

```
健全内容保障机制，增强政策解读实效。
优化网站功能架构，提升便民服务效能。
规范新媒体运维管理，强化备案动态管控。
```

```
着力推进向新向优发展，产业转型升级步伐加快。
着力深化改革扩大开放，先行先试探路富有成效。
```

丙式的特点是**前后两半各自独立成义，且互为因果**——前半是动作，后半是效果。报告里那四个一级标题更极端，全部是"一X一X，……"的七言对仗（一年接着一年干／一张蓝图绘到底／一鼓作气勇争先／一以贯之转作风）。

**选法**：写意见或规范性的部署通知用甲；写领域清单型方案（"交通服务""家政服务"）用乙；写通报、报告用丙。

> ⚠️ **我原先写的是"一篇之内只用一种，甲乙混用最难看"，这条被真件推翻了。** 黑龙江那篇通报就是在同一篇里换了三种：讲情况用乙（"（一）全省政府网站检查情况。"），讲问题用"关于……方面"（"（一）关于政府网站建设管理方面……"），讲要求用丙（"（一）健全内容保障机制，增强政策解读实效。"）。
>
> 真正的规矩是：**同一节之内只用一种，跨节可以换，而且要换得有道理**——讲"是什么情况"用名词，讲"要怎么做"用动宾。全篇硬套一种反而僵。但**同一节里的五六条必须齐**，那是眼一看就露馅的地方。

## 二·补｜还有一种是"标题不带句号"

民政部指引附件里是这么写的：

```
（一）设置方式
（二）功能定位
（三）运行机制
```

标题独立成行、不带任何标点，下面另起一段。这类出现在**指引、办法、细则**的附件里，是三层结构（`一、`→`（一）`→`1.`）的中间层。带句号的（甲、乙、丙）都是"标题＋正文同段"或"标题后紧接正文"，不带句号的是纯目录。

**判据**：标题后面紧跟着正文（哪怕换行），就要句号；标题独占一行、正文另起段，就不加句号。

## 三、一级标题的字数不齐，齐的是句式

这点跟我原来想的不一样，得先把我写错的地方纠正掉：**十篇里只有一篇的一级标题字数是相等的。**

```
意见（国发11号）    重点任务(4) / 支撑保障(4) / 组织实施(4)          ← 齐，因为全是通用块名
意见（国办发28号）  总体要求(4) / 强化赛事活动供给(8) / 深化赛事融合发展(8) …  ← 4 配五个 8
通知（国办发24号）  健全行业账款支付规则(10) / 加强大型企业支付行为监管(12)
                    规范管理非现金支付工具(11) / 强化资金传导效能和融资支持(13)
通知（国办发2号）   激发重点领域发展活力(10) / 培育潜力领域发展动能(10) / 加强支持保障(6)
通报（黑龙江）      检查总体情况(6) / 存在的主要问题(7) / 下一步工作要求(7)
报告（福建省）      23 / 22 / 24 / 22 字                                 ← 排比型，追求一致
```

**真规律是三条，不是"字数必须齐"：**

1. **通用块名只有四个字，可以直接用，也可以和长标题混排。**「总体要求」「重点任务」「支撑保障」「组织实施」这几个读者认得，写四个字不显得单薄，接在五个八字标题前面也不突兀。这是唯一的"短配长"豁免。
2. **个性化标题按内容定长，6—13 字都在正常范围内，相邻条差三四字不算毛病。** 13 字的"强化资金传导效能和融资支持"和 10 字的"健全行业账款支付规则"摆在一起，真件就这么写。
3. **只有排比型（政府工作报告）才追求字数一致**，而且它追求的是对仗，不是等长——22 到 24 字，句式全是"一X一X，……"。

**真正要知道的禁忌**：别让一条 4 字的「加强保障」混在五条 13 字的动宾中间——那不是通用块名，是偷懒。通用块名和个性化标题的界线是**这个词放之四海而皆准，还是只在本文成立**。

> 批复不参与这项讨论：它的一级"标题"是整条条款，实测 40—366 字，没有字数概念。

## 四、收尾：十篇没有一个程式化结语

这是这批真件最整齐的一条：**决定、意见×2、批复×2、报告、通报、通知×3，全部自然收束，零个"特此通知""此复""特此报告"。**

具体怎么收的：

```
批复    → 「重大事项及时按程序向党中央、国务院请示报告。」
通知    → 「各地区、各有关部门要……确保……」
通报    → 「各地各部门要……切实做到账实相符。」
意见    → 「国家发展改革委要会同有关部门扎实推进工作……」
报告    → 号召句
```

**规律是：用最后一条要求收尾，而不是用一个固定的客套句收尾。** 这跟"75%—87% 自然收束"的统计是一致的，只是在这十篇里是 100%。

> ⚠️ **一个容易误判的地方**：国办发2号里确实出现了"请认真贯彻执行"，但它在**开头**——"《方案》已经国务院同意，现印发给你们，请认真贯彻执行。"这是印发式通知的承启句尾句，不是收尾语。搜"请遵照执行"时如果不看位置，会把这条误算成程式化结语。

> 注意：这不等于"此复""特此通知"是错的。基层和部门公文用它们很常见，GB/T 9704 也没有禁止。但**中央级真件在系统性地避开它们**，你要写得像这个层级的东西，就别用。

## 五、动词骨架

十篇里出现两次以上的搭配，按频次：

```
推动·高质量发展(8)  加快·推进(7)      支持·有条件的(6)  加快·培育(6)
支持·符合条件(5)    支持·力度(5)      加强·组织领导(3)  鼓励·有条件的(3)
加强·统筹协调(2)    加强·工作指导(2)  鼓励·社会力量(2)  强化·协调配合(2)
健全·标准体系(2)    落实·落细(2)      落实·举措(2)      优化·公共服务(2)
推动·科技创新(2)    规范·化发展(2)    严格·落实耕地(2)  坚持·以人民为中心(2)
```

能看出两个稳定的套子：

**「支持／鼓励＋有条件的（地方）」**——凡是不强制、只鼓励的事，一律加这个限定。这是公文里表达"不搞一刀切"的标准句式，十篇里出现十几次。

**「加强／强化＋组织领导／统筹协调／工作指导／协调配合」**——凡是讲责任落实，用的都是这四个词，几乎不用别的。写"各部门要密切配合"不如写"强化协调配合"。

## 六、一句话总结这批真件的文风

**条款短、动词实、不写主语、不用修辞、结尾落在要求上。**

对照一下 AI 初稿常见的毛病：句子长而绕、爱加"综上所述"、爱用破折号转折。这十篇里破折号 0 个、"综上所述" 0 次。

但**"进一步""切实"这类词不是零，是少**——四万二千字里各出现 8 次，折合每万字两次。所以别把它们当禁用词，要当**配额词**：一篇两三千字的稿子里出现一两次正常，出现七八次就是拿它们填空。同理"努力"7 次、"有效地"0 次、"高度重视"1 次、"狠抓"1 次。

这个数是最好用的自检项之一——搜一遍，超过每万字三次就该回头看，是不是有具体动作没写出来，只好用虚词顶着。

## 七、这批样例的边界

- 全是**中央级和省级**，没有市县一级。基层公文的句子通常更短、更口语，别把这批的句长直接套到县级材料上。
- 缺**函**和**会议纪要**——公开渠道基本不发这两类。
- 缺**事务性材料**（调研报告、讲话、经验材料），那类基本不公开，参数仍以 `参数卡.md` 为准。
- 四篇带"本文有删减"，结构可信、篇幅不可信。见 `索引.md`。
