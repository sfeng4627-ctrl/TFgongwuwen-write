# TFgongwuwen-write

公务员公文写作工作台。核心是一张从真实公文里数出来的参数表，加一个写完能验的自检脚本。

## 怎么装

按 Agent Skill 的格式组织：`SKILL.md` 带 YAML frontmatter，其余是它引用的资料和脚本。

```bash
git clone https://github.com/<用户名>/TFgongwuwen-write.git ~/.workbuddy/skills/tfgongwuwen-write
```

放进技能目录后重启客户端，它就会出现在技能列表里。触发词见 `SKILL.md` 的 description——说「写个通知」「起草请示」「帮我改这篇公文」就会命中。

不想装成技能也能用：脚本是零依赖的纯标准库，直接跑就行。

```bash
python scripts/check_params.py 你的稿子.md --genre 调研报告
python scripts/check_params.py 你的稿子.md --genre 批复   # 法定公文查体例
```

## 我为什么攒这套东西

我表哥考上了乡镇的选调生，去了就忙。白天跑村入户，晚上写稿子，桌上的材料永远写不完。三个月，人从一个精神小伙变成了眼袋很重的中年男人。

我看他实在扛不住，就自荐给他攒了这么一套东西。

写公文最磨人的地方不是写不出来，是**写完心里没底**——觉得哪儿不对，又说不清哪儿不对，改了三遍还是那个感觉，最后要么交上去被退，要么自己硬着头皮发。谁也没法给他一个客观的回答，因为"像不像公文"这件事，从来没人量过。

所以我就去量了。把公文的句长、顿号密度、标题层级、力度词配额这些参数一项一项数出来，找到各文种的特征区间，再配个脚本，写完跑一遍，哪儿偏了一眼能看见。

后来越攒越多，成了现在这个样子。定位一直没变：**不替你写，只让你写完心里有数。**

## 四条命令

```bash
# 写完一篇事务性材料，验一下像不像公文
python scripts/check_params.py 草稿.md --genre 调研报告

# 写的是法定公文（通知/批复/请示/报告/函/纪要/决定/通报/意见）：查体例，不查参数
python scripts/check_params.py 草稿.md --genre 批复

# 不确定该写成什么文种，让它猜
python scripts/check_params.py 草稿.md --match

# 把你自己的稿子变成参数（首次用之前先读第八节）
python scripts/ingest_corpus.py --genre 工作总结
```

法定公文走的是另一条路：它的结构由《党政机关公文处理工作条例》和 GB/T 9704 锁死，篇幅从 623 字（批复）到两万多字（省政府工作报告）都合法，拿统计参数去卡它必然一堆假警报。所以那一路只查四组——承启句、层级分条、篇名要素、用语红线。

零依赖，Python 3.8+ 就能跑，不用装任何包。

## 三件必须先知道的事

**一、参数是描述性的，不是合格线。** 它说的是"这批真公文平均长这样"，不是"你必须长这样"。语料里写得最好的几篇，逐项跑自检没有一篇全项达标。**好文章不整齐。**

**二、自检只认硬冲突。** 报告里 `✗` 必须改（那是文种写错了），`⚠` 是先问你一句"我这项偏离是因为写进了什么"，答得出来就留着。

**三、不编数据。** 缺数字、缺文号、缺人名日期，一律走 `【待补：xx】`，绝不杜撰。占位符汇总会单独列给你。

## 真正的用法

这套参数描述的是一批真实公文的平均样子，不一定是你所在系统、你所在层级的样子。省级机关的讲话和县级机关的讲话，要求词能差一倍。

想让它真正贴合你，只有一条路：把自己的稿子喂进 `我的语料/原文/`，跑 `ingest_corpus.py` 重算。详见 `SKILL.md` 第八节和 `我的语料/README.md`。

## 往下还能走三步

**第一步，换掉参数。** 现在这张参数表描述的是一批真实公文的平均样子。等你把自己的稿子攒到 15—20 篇、跑出自己那一列中位数，这套东西才真正长在你身上。到那时候，参数是你自己的，判断标准也是你自己的。

**第二步，接上排版。** 写和排是两件事。这本只管写到"像"，不管版式。出稿之后交给 `gongwen`（公文排版，按 GB/T 9704-2012 生成 DOCX）——发文机关标志、发文字号、主送机关、版记、页码它管，一条链就闭合了。

**第三步，想拿它干别的，先看许可。** 这一点写在下面，请务必读完再决定用途。

## 分享与授权

**可以免费分享，随便传。** 许可证里有一节 Distribution License，直接给了分发权，连"带改动的版本"也允许一起发。所以转发、上传网盘、发 GitHub、拷给同事，都在范围内。

**有一条义务必须守：谁从你这儿拿到一份，就得同时拿到这份许可证文本，或者它的网址。** 这是许可证 `## Notices` 那节的硬要求，也是唯一一条。

### 哪些不行

- 收费代写、按次付费使用
- 做成付费产品或付费服务

### 一个用词上的提醒

对外介绍时，说「**免费分享**」或「**源码可见**」是准确的，说「**开源**」不准确。开源有明确的定义（OSI 认证），要求不得对使用领域设限；这份许可证恰恰限制了商业用途，所以它不是开源软件。懂行的人会在这一点上较真。
