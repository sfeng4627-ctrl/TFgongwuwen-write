# 我的语料

这个目录是空的，等你填。填进去之后，这套 skill 才会慢慢变成"你的"而不是"通用的"。

## 三步

**第一步｜把稿子扔进 `原文/`**

```
我的语料/
├── 原文/          ← 你的稿子放这儿，.md 或 .txt
├── _stats/        ← 脚本生成，别手动改
└── README.md
```

选稿标准，按重要性排：

1. **同层级、同系统**。写县级的材料就只放县级的。混进省级稿，算出来的中位数是个大杂烩，反而不如内置参数
2. **公认写得好**。别放自己都不满意的，那是在给自己立错标杆
3. **15—20 篇起步**。少于 10 篇，中位数会被一两篇反常的稿子带跑
4. **真人写的**。AI 生成的绝对不要放，那是在拿自己的输出训练自己，越跑越偏

**第二步｜跑脚本**

```bash
# 同文种的放在一起跑一次
python scripts/ingest_corpus.py --genre 工作总结

# 想看全貌就不标文种
python scripts/ingest_corpus.py
```

`--genre` 的值必须是参数表里有的：调研报告、领导讲话、工作意见、经验材料、工作方案、经验总结、短经验材料。法定公文（通知/请示/批复/函）没有统计参数，跑了也只能看你这一侧的分布。

**第三步｜看报告，决定换不换基准**

打开 `_stats/参数汇总.md`，看第二节那张表。判断很简单：

```
差得不多（句长差 3 字内、顿号差 3‰ 内）→ 内置参数够用，别折腾
差得明显（某项差出一档）                → 以后按你这列写
```

## 后续怎么用

报告不会自动生效——它只是一份参照。真正用起来是这两条：

- **写之前**：看 `_stats/参数汇总.md` 第二节，把你自己的中位数记在手边
- **自检之后**：报告里的"常见区间"是内置的，判断时按你的中位数看，不看那个区间

将来如果你想让自检脚本直接认你的参数，改 `scripts/check_params.py` 里的 `REF` 字典就行——把某一文种那一行的三元组 `(p25, p75, 中位)` 换成你算出来的。`_stats/参数汇总.json` 里就是按这个格式存的，抄过去即可。

## 注意

- 这个目录不会自动清理，也不会外发。脚本只读原文、只写 `_stats/`
- 涉密文件别放。真要放，自己确认过再放
- 原稿改了要重跑，报告是整体重算的，不追加
